# projeto-estudo-de-pomodoro
Sistema Pomodoro com configuração de tempo de estudo e descanso; 🔄 Definição da quantidade de ciclos; 📊 Registro e análise do tempo estudado; 🎯 Monitoramento da aba de estudo selecionada; 🔔 Notificações para incentivar o retorno quando o usuário sai da aba 🗄️ Integração com um pequeno banco de dados para armazenamento das informações.
